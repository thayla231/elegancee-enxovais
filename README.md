# Elegance Enxovais

## Sobre o projeto

O Elegance Enxovais é um site criado para facilitar a compra de produtos de cama, mesa e banho.

A ideia é permitir que o cliente veja os produtos, faça seus pedidos e escolha entre retirar na loja ou receber por entrega.

## O que o site tem

- Produtos de cama, mesa e banho
- Visualização dos produtos
- Carrinho/pedidos
- Opção de entrega ou retirada
- Escolha de pagamento

## Tecnologias

- HTML
- CSS
- JavaScript
